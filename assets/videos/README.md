# Vídeos

No hay vídeos originales (la referencia es una grabación de pantalla, de la que no se pueden extraer).
Para usar vídeo real, copia aquí los MP4 y escribe su ruta en `VIDEOS` al inicio de `js/main.js`:

| Clave   | Capa                                  | Ruta sugerida                 |
|---------|----------------------------------------|-------------------------------|
| desert  | 01 Despegue · coche en el desierto     | assets/videos/desierto.mp4    |
| wheel   | 01 Despegue · primer plano de rueda    | assets/videos/rueda.mp4       |
| road    | 01 Despegue · pista con polvo          | assets/videos/pista.mp4       |
| jump    | 02 El salto · vista cenital            | assets/videos/salto.mp4       |
| wall    | 03 La pared · pared y techo            | assets/videos/pared.mp4       |

Se reproducen con `autoplay muted loop playsinline`. Si la ruta está vacía se usa el arte procedural de `assets/images/`.
